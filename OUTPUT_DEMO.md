### 🚀 **Command Examples & Outputs**

#### **Basic Usage**
```bash
crashlens policy-check logs.jsonl --policy-template all
```
**Output:**
- ✅ `policy-violations/reports/violations-summary.md`
- 📊 Console: "Saved markdown report to policy-violations\reports\violations-summary.md"

#### **Detailed Analysis**
```bash
crashlens policy-check logs.jsonl --policy-template all --detailed
```
**Output:**
- ✅ `policy-violations/reports/violations-summary.md`
- ✅ `policy-violations/traces/violations-detailed.json`
- 📊 Console: "Saved markdown report to...", "Saved detailed JSON to..."

#### **Custom Directory (NEW!)**
```bash
crashlens policy-check logs.jsonl --policy-template all --detailed --out-dir crashlens-reports/
```
**Output:**
- ✅ `crashlens-reports/violations-summary.md`
- ✅ `crashlens-reports/violations-detailed.json`
- 📊 Console: "Saved markdown report to crashlens-reports\violations-summary.md"

#### **File Collision Protection (NEW!)**
```bash
# Run same command twice - second run adds timestamp
crashlens policy-check logs.jsonl --policy-template all --detailed --out-dir reports/
```
**First Run Output:**
- ✅ `reports/violations-summary.md`
- ✅ `reports/violations-detailed.json`

**Second Run Output:**
- ✅ `reports/violations-summary-20250817-161723.md`
- ✅ `reports/violations-detailed-20250817-161723.json`

#### **Force Overwrite (NEW!)**
```bash
crashlens policy-check logs.jsonl --policy-template all --detailed --out-dir reports/ --force
```
**Output:**
- ✅ `reports/violations-summary.md` (overwrites existing)
- ✅ `reports/violations-detailed.json` (overwrites existing)

#### **Custom Audit Report**
```bash
crashlens policy-check logs.jsonl --policy-file my-policy.yaml \
  --detailed \
  --out-report policy-violations/reports/audit-2025-08-17.md \
  --out-detailed policy-violations/traces/audit-2025-08-17.json
```
**Output:**
- ✅ `policy-violations/reports/audit-2025-08-17.md`
- ✅ `policy-violations/traces/audit-2025-08-17.json`

#### **CI/CD Mode**
```bash
crashlens policy-check logs.jsonl --policy-template all \
  --detailed --quiet --fail-on-violations --strip-pii
```
**Output:**
- ✅ `policy-violations/reports/violations-summary.md` (with PII removed)
- ✅ `policy-violations/traces/violations-detailed.json` (with PII removed)
- 📊 Console: Only essential output, exits with code 1 if violations found

### 🎯 **Key Benefits Demonstrated**

1. **Professional Organization**: No more scattered files in project root
2. **Clear Separation**: Summary reports vs detailed analysis files
3. **Flexible Directory Control**: `--out-dir` for custom organization
4. **Smart File Protection**: Automatic timestamp collision detection
5. **Force Overwrite Option**: `--force` for CI/CD and automation scenarios
6. **Privacy Controls**: PII scrubbing clearly indicated in reports
7. **CI/CD Ready**: Quiet mode, exit codes, and structured outputs
8. **Enterprise Features**: Complete metadata, cost analysis, and compliance indicators

### 📈 **Impact Summary**

- **Before**: Single `report.md` file in project root
- **After**: Organized `policy-violations/` structure with clear separation
- **Enhancement**: Detailed JSON analysis with trace grouping
- **Privacy**: Built-in PII controls and content removal options
- **CI/CD**: Clean integration with proper exit codes and quiet mode
- **Scalability**: Foundation for advanced analytics and dashboard integration

This redesign transforms CrashLens from a basic reporting tool into a comprehensive AI governance platform suitable for enterprise deployment.
